# カチレンタン 〜価値観トップ3を当てろ！〜

出題者の「価値観トップ3」を、順位まで予想するゲームです。

- **みんなのスマホで**：部屋を作ってURLを送ると、各自のスマホで参加できます（2〜10人）
- **1台を回して遊ぶ**：スマホ1台を手わたしで（2〜6人）

## 得点
| 役 | 内容 | 点 |
|---|---|---|
| サンレンタン | 3つとも順位までぴったり | 6 |
| サンレンプク | 3つとも当たり（順位ちがい） | 4 |
| ニレンタン | 1着と2着がぴったり | 3 |
| プクプク | 2つ当たり | 2 |
| タン | 1つ当たり | 1 |

## ファイル
- `themes.js` … ふつうのお題（200問・7つの選択肢）
- `themes_deep.js` … DEEPのお題（100問・仲良しメンバー向け）
- `firebase-config.js` … Firebase の設定（空だとデモモード）
- `database.rules.json` … Realtime Database のルール
